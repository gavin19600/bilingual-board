# 이중언어 칠판

초등 다문화 학생의 한국어 공부를 돕는 칠판입니다. 선생님이 한국어 자료를 올리면 학생의 모국어 번역을 문장별로 나란히 보여 주고, 자료 위에 전자칠판처럼 쓰고 지울 수 있습니다.

## 할 수 있는 일

- PDF, 사진, 카메라로 찍은 사진, 붙여 넣은 글을 자료로 올리기
- 문장별 번역, 쉬운 한국어, 낱말 익히기 보기 (15개 언어)
- 크레용, 형광펜, 지우개, 직선, 네모, 동그라미로 필기하기
- 한국어나 번역을 숨겼다가 눌러서 확인하기
- 원문과 번역이 함께 들어간 학습지를 그림이나 PDF로 저장하기
- 선생님이 보낸 쪽을 학생이 QR 코드로 열어 보기

## 번역하는 세 가지 방법

1. **바로 번역**: Claude 안에서 이 페이지를 열었을 때만 됩니다. 페이지를 연 사람의 Claude 계정으로 번역합니다.
2. **JneGPT 에이전트**: JneGPT의 "이중언어 번역" 에이전트로 번역한 뒤, 결과를 "번역 결과 붙여넣기"에 넣습니다.
3. **학생에게 보내기**: 선생님이 번역한 쪽을 학생 화면으로 보냅니다. Claude 안에서 연 선생님만 보낼 수 있습니다.

## 이 저장소의 파일을 그대로 열면

`index.html` 한 파일로 되어 있습니다. Claude 밖(예: GitHub Pages)에서 열면 자료 보기, 필기, 번역 결과 붙여넣기는 되지만 다음 기능은 작동하지 않습니다.

- 바로 번역
- 학습지 저장, 칠판 그림 저장
- 학생에게 보내기

## 붙여 넣는 번역 형식

```
[S] 한국어 원문 문장
[E] 쉬운 한국어 (필요할 때만)
[T] 학생 모국어 번역
[V] 낱말 | 번역 | 쉬운 한국어 풀이
```
